Collaborative document editor

In development · Since April 2026

CoCanvas

A document, shared as it changes.

CoCanvas is a document editor where several people can write at the same time. I’m building it with Yjs, Node.js and WebSocket to support concurrent changes and synchronisation when a client reconnects.

At its core is a CRDT: a data structure designed to merge concurrent changes. Alongside the document itself, the editor handles the presence information that helps people see who else is there.

Built with

TypeScript · React · Node.js · WebSocket · Yjs · Redis Streams · PostgreSQL

The core pieces

Editing together

Yjs and a WebSocket connection support concurrent editing. Multiplayer cursors, selections and online status make the shared session visible.

Finding the document again

Snapshots and incremental updates are used to restore a document. Reconnection handling lets a returning client synchronise its state.

Where it stands

CoCanvas is still in development. I have not published performance measurements, so I’m not making claims about supported user counts or synchronisation latency.
